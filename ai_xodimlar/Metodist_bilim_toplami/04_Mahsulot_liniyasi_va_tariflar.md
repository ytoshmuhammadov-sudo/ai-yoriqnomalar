# MAHSULOT LINIYASI VA TARIFLAR

## 1. Nega liniya kerak
Bitta mahsulot bilan mijoz bir marta sotib oladi. Liniya bilan u bepuldan boshlab, ishonch ortgan sari qimmatroq mahsulotga o‘tadi. Bitta mijozdan tushum bir necha barobar oshadi.

## 2. To‘rt pog‘ona
1. BEPUL (lid-magnit): chek-list, sinov darsi, konsultatsiya, namuna. Maqsad: tanishish.
2. KIRISH (arzon, tez natija): kichik mahsulot, mini-kurs, birinchi muolaja, kichik to‘plam. Maqsad: birinchi xarid va ishonch.
3. ASOSIY: to‘liq natija beradigan mahsulot. Daromadning asosiy qismi.
4. PREMIUM: shaxsiy yondashuv, tezlik, VIP xizmat. Narxi asosiydan 2-4 barobar.
Qo‘shimcha: DOIMIY mahsulot (obuna, klub, har oylik xizmat): barqaror daromad.

## 3. Soha bo‘yicha misollar
O‘quv markazi: bepul test → 1 oylik intensiv → 4 oylik kurs → individual darslar
Go‘zallik saloni: bepul diagnostika → 1 ta muolaja → 5 ta muolaja kursi → yillik parvarish dasturi
Kiyim do‘koni: stil maslahati → aksessuar → kiyim to‘plami → shaxsiy stilist bilan xarid
Mebel: bepul o‘lchov va 3D → kichik mebel → oshxona/shkaf → to‘liq interyer

## 4. Uch tarif qoidasi
MINI: asosiy natija, mustaqil. Narx: past.
STANDART: + yordam va bonuslar. Eng ko‘p sotiladi. Eng foydali qilib ko‘rsating.
VIP: + shaxsiy ishlash, tezlik, maxsus imkoniyatlar. Narx: standartdan 2-3 barobar.
VIP kam sotilsa ham kerak: u standartni arzonroq va foydaliroq ko‘rsatadi.

## 5. Tarif jadvali (shablon)
Imkoniyat | Mini | Standart | VIP
Asosiy mahsulot | ✓ | ✓ | ✓
Qo‘llab-quvvatlash | — | ✓ | ✓ shaxsiy
Bonuslar | — | ✓ | ✓ + maxsus
Muddat / tezlik | | |
Kafolat | | |
Narx | | |
Farqlar bir qarashda tushunarli bo‘lsin. Har tarifda 5-7 qatordan oshmasin.

## 6. Qo‘shimcha sotuv
- UPSELL (qimmatroq variant): "Standart o‘rniga VIP olsangiz, ... ham kiradi."
- CROSS-SELL (to‘ldiruvchi): "Ko‘ylakka mos sumka ham bor."
- PAKET: bir nechta mahsulot birga arzonroq.
Eng yaxshi payt: xarid qarori qabul qilingan paytda yoki birinchi natijadan keyin.

## 7. Chegirma siyosati
- Chegirmani tez-tez bermang: mijozlar chegirmani kutishni o‘rganadi.
- Narxni tushirish o‘rniga qiymat qo‘shing: bonus, bepul yetkazish.
- Chegirma faqat aniq sabab bilan: pilot guruh, birinchi xarid, bayram, doimiy mijoz.
